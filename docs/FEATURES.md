# Features

## Current Features

### Basic Arithmetic Operations
- **Addition (+)**: Add two numbers together
- **Subtraction (-)**: Subtract one number from another
- **Multiplication (*)**: Multiply two numbers
- **Division (/)**: Divide one number by another
  - Includes error handling for division by zero

### Number Input
- **Numbers (0-9)**: Input any digit
- **Decimal Point (.)**: Support for decimal numbers
- **Prevents Multiple Decimals**: Automatically prevents adding more than one decimal point per number

### Special Functions
- **Square (x²)**: Calculate the square of a number
- **Backspace (←)**: Delete the last entered digit
- **Clear (C)**: Clear the display and reset the calculator

### User Interface
- **Display**: Large, right-aligned text field showing current input and results
- **Grid Layout**: Organized button layout for easy access
- **Error Handling**: Shows "Error" message when encountering division by zero
